# 壁纸库

浏览四个壁纸站，搜索、分类、续页并预览高清图片，管理本机图库与应用背景。Wasm 负责站点 URL、HTML / JSON 解析、图片身份与会话，HTML 界面负责预览与交互，宿主提供 HTTP、图片资源、外链与图库服务。版本和最低宿主要求见[清单](./extension.json)，配套宿主见[发布指南](../../docs/publishing.md#固定配套宿主)。

## 功能与授权

页面留白和普通图片卡片跟随宿主皮肤强度；输入、下拉菜单、图片预览和确认弹窗保留阅读底色，规则见 [宿主 SDK](https://github.com/YanChao001/serial-workbench/blob/main/sdk/README.md#%E9%BB%98%E8%AE%A4%E5%A4%96%E8%A7%82%E4%B8%8E%E5%8A%A8%E6%95%88)。

`wallpapers:manage` 是必需权限，用于列出图库、通过对话框导入、重命名、移除图片、设置本应用背景及打开图库设置；作用范围限于应用内部。本机功能可离线使用。

其他能力分别可选授权：

| 权限                   | 用途                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------- |
| `network:https`        | Wasm 通过 HTTP effect 读取清单声明的四个壁纸站的公开 HTTPS 列表                         |
| `network:images`       | 通过通用资源服务下载公网 HTTPS 缩略图或原图，预览、另存及加入图库                       |
| `links:open`           | 用户点击后，在外部浏览器打开图片来源页，核对来源与使用许可                              |
| `network:system-proxy` | 宿主选择系统代理时允许上述已获授权的网络请求使用代理；不额外授予图源 API 或图片网络权限 |

界面按授权启用入口，连接方式统一继承宿主“设置 → 网络”。系统代理授权需与列表或图片网络授权配合使用，具体规则见[网络连接](#网络连接)。

## 图源、预览与资源

通过下拉列表切换图源，输入关键词后点击搜索或按 `Enter`。每次读取一个站点列表页，最多显示 24 张不同图片；接近页尾自动追加下一页，也可手动加载或重试。续页按图片身份去重，最多 40 页、960 个身份，遇到空页、全为已看图片或站点末页时结束。搜索、换源与分类从第一页开始，失败保留已加载图片和实际筛选。会话恢复最近一页，完整长页保留在当前打开的界面中。

关键词会发送至所选站点，使用全站搜索范围、分类归一为“全部”；清空关键词后可切换分类。壁纸汇与猫猫壁纸酷支持中文检索，壁纸汇的无关推荐会被过滤；其他两站建议使用英文关键词。语言切换与会话恢复直接使用已有结果。

| 图源            | 站点                                     | 请求与图片身份                                                                                                                    |
| --------------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 壁纸汇          | [免费壁纸](https://www.bizhihui.com/)    | 首页、分类与 `search.php?q=` 搜索；缩略图与下载文件绑定 `s.panlai.com` 同一路径，来源保留实际详情页。                             |
| 猫猫壁纸酷      | [壁纸目录](https://www.wallcoo.com/)     | 公开 `/wp-json/bc/v1/wallpapers` 目录提供搜索、分类与页码；使用同一文件的缩略图与 `largeUrl` 高清适配图，完整原图通过来源页获取。 |
| WallpapersCraft | [桌面壁纸](https://wallpaperscraft.com/) | 最新、分类与 `/search/?query=`；限定 1920×1080 文件，缩略图和下载图绑定同一图片名称与编号。                                       |
| GoodFon         | [免费桌面壁纸](https://www.goodfon.com/) | 最新、分类与 `/search/?q=`；从列表读取实际尺寸，缩略图与原文件绑定相同路径、图片名及来源详情页。                                  |

插件按用户操作读取公开网页或 JSON 列表。网页结构变化、访问限制、限流或网络异常时显示错误，并保留上次成功列表与筛选，供重试或切换图源。

使用或分发图片前，通过“来源”核对原作归属、站点条款与许可；免费下载本身不构成使用授权。WallpapersCraft 提供 1920×1080 文件，猫猫壁纸酷保存公开高清适配文件；“保存高清图”使用这些版本，完整原图请查来源页。

撤销 HTTPS 权限后保留已显示列表，重新授权后查询或刷新。图库预览繁忙时保留列表并提示重试。

本机图库先显示元数据卡片，再逐张加载缩略图；在线搜索、下载和图库读取独立进行。图库写入期间限制重复操作，后台读取保留界面可用，旧响应按操作版本隔离。

设置背景时只在目标图片显示进度，保存期间可继续切页、搜索或刷新。原生确认后，用轻量回执更新当前项与 revision，保留名称、容量和缩略图。接口见[宿主壁纸服务契约](https://github.com/YanChao001/serial-workbench/blob/main/docs/extensions.md#%E5%A3%81%E7%BA%B8%E5%9B%BE%E5%BA%93%E4%B8%8E%E5%9B%BE%E7%89%87%E6%90%9C%E7%B4%A2)。

列表请求经 HTTP effect / `host-result` 完成，验证来源、筛选、页码、effect ID、URL 与响应后，一起替换列表和成功筛选。schema 4 会话保存有界元数据、分页和已见身份；图片字节与原生资源句柄只用于当前运行。旧搜索会话、未来或损坏状态保留原件并拒写。

图片通过宿主通用资源服务下载和重绘为安全 data URL，按可见区域优先加载，并使用有界内存缓存。资源绑定当前安装与窗口，操作结束后释放句柄；撤权、失效或卸载时清空缓存。初始化、前台操作、图片和检查点保存共用消息桥并发调度，为用户操作保留容量。

大图先显示缩略图，再通过 `fetch-image` 的 `preview: "large"` 获取高清适配图：壁纸汇使用详情图 `-arthumbs`，GoodFon 使用 `/wallpaper/nbig/`，其余两站使用上表文件。安全预览最长边 2560 像素、JPEG data URL 最多 256 KiB；卡片缩略图最多 320 像素、24 KiB。所选大图有独立加载空间，关闭或切换时取消旧请求，失败可重试。预览支持方向键切换、查看尺寸与来源，`Esc` 按层关闭并恢复焦点。

- **保存高清图**：资源服务核验类型、解码与额度，再通过原生另存对话框保存文件。已知源尺寸超过每边 8192 像素或 1600 万像素时改用站点高清适配图，完整尺寸可从来源页获取。
- **加入图库**：获取高清适配图，交给图库 `import-resource` 重绘压缩；界面按响应中的 `limit` 显示图库容量。图库保存适合应用背景的压缩副本，另存高清文件使用上一项操作。
- **应用背景**：选择图库图片及覆盖 / 完整显示方式，使用既有设置 revision CAS 保存并同步多窗口；冲突时刷新后重新选择。
- **本机管理**：本地图片通过用户选择导入；点击缩略图设为应用背景，右上角勾选表示当前使用项，名称旁的铅笔与垃圾桶图标直接重命名或移除。移除前确认；移除当前使用项后恢复纯色背景，不删除用户原始文件。其他窗口已经修改背景设置时，旧快照的移除操作会提示冲突并保留图片，刷新后再操作。

下载文件最多 16 MiB、每边 8192 像素、总计 1600 万像素。超额原图可使用适配图预览，下载与导入按宿主反馈处理。公网 URL、类型、解码、TLS 与额度由[原生安全边界](../../docs/security.md#原生服务与外部来源)核验。

## 网络连接

在宿主“设置 → 网络”选择直接连接或跟随系统代理，默认跟随系统代理。图源 HTTP effect 与 `fetch-image` 均省略 `networkMode`，随请求继承宿主设置。直连核验并固定公网 DNS 地址，VPN Fake-IP 等合成保留地址可能被拒绝。

系统代理需独立授予 `network:system-proxy`；未授权、没有匹配代理或命中排除规则时直连并检查 DNS。代理使用宿主支持的系统配置，HTTPS、来源与方法限制继续生效；代理远端解析的最终 IP 无法由宿主核验，授权时需接受这一信任边界。支持范围及显式 `networkMode` 规则见[宿主扩展指南](https://github.com/YanChao001/serial-workbench/blob/main/docs/extensions.md#%E6%9D%A5%E6%BA%90%E4%B8%8E%E6%8E%88%E6%9D%83)。

## 开发与验证

从市场仓库根目录运行：

```sh
cargo test --locked --manifest-path plugins/wallpaper-browser/Cargo.toml --target-dir target/wallpaper-browser-native
cargo clippy --locked --manifest-path plugins/wallpaper-browser/Cargo.toml --target-dir target/wallpaper-browser-native --all-targets -- -D warnings
cargo build --locked --release --target wasm32-unknown-unknown --manifest-path plugins/wallpaper-browser/Cargo.toml --target-dir target/wallpaper-browser
node --test plugins/wallpaper-browser/ui/main.test.mjs
```

依赖用途与版本见 [Cargo.toml](./Cargo.toml) 和 [Cargo.lock](./Cargo.lock)：`serde` / `serde_json` 处理状态与响应，`url` 负责 URL 规范化，均采用 MIT / Apache-2.0 双重许可，支持原生测试和 Wasm。

原生测试覆盖四站解析、筛选、图片身份、去重、分页、失败保留与 HTTPS 来源。按[单插件验收](../../docs/testing.md#聚焦单个插件)运行 [`smoke.json`](./smoke.json)，检查真实 Wasm 的 effect、回执和授权；UI 回归覆盖高清请求、切换、重试与资源释放。资源、网络、图库 CAS、真实网站、WebView 和对话框按[原生服务验收](../../docs/testing.md#固定原生服务验收)检查。

图源错误保留既有图库与背景偏好。会话文件绑定插件及 UI 文档版本，恢复时使用匹配版本。
