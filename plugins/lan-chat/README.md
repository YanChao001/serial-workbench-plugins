# 内网通信

使用宿主原生 TCP 服务，在可信局域网设备间收发文字、表情、图片和文件。会话栏支持附近设备、最近会话、搜索和未读计数；标题旁的“连接与设置”提供通信开关、手动连接、诊断与数据管理。界面主题、字体、控件及浮层材质由宿主注入，并跟随中英语言切换，昵称与正文保留用户原文。

## 两台设备开始聊天

通信和设备公告均以**明文**传输，没有端到端加密或远端身份认证，昵称与节点身份由对方自行声明。仅连接可信设备，避免传输密码等敏感信息。

1. 两台设备使用相同配套原生实现的宿主与插件，在插件中心授予 `messaging:lan` 并启用。最低宿主要求见[清单](./extension.json)，版本与源码提交按[配套宿主](../../docs/publishing.md#固定配套宿主)核对。
2. 两端打开已授权的插件，界面首次成功读取状态后自动开启局域网监听和设备发现；已有服务继续使用。附近设备随公告出现在会话栏，点选即可连接，无需填写 IP。真实协议握手完成后才成为最近会话；发现名单不写入历史。
3. 需要修改昵称时，点击会话栏标题旁的“连接与设置”；监听端口和手动 IP 操作位于“手动连接”折叠区。面板显示实际绑定的私有 IPv4 和端口，TCP 默认端口为 `45873`；端口被占用时先停止，再更换端口。也可填写对方显示的 IP 和端口，点击“连接设备”。
4. 选择会话，在底部输入消息，点击发送或按 `Enter`；`Shift + Enter` 换行，输入法组合期间的回车不发送。“等待送达回执”表示尚未确认送达，对端原子保存并回传 ACK 后才显示“已送达”。

手动连接接受数字形式的私有、回环或允许的本地链路 IP。发现使用 UDP `45874` 在所选网卡的子网广播，附近记录定时过期；建立聊天连接仍需点选设备。监听优先使用可用的私有默认路由，否则回退到已启用的私有网卡；没有可用私有 IPv4 时仅绑定回环地址。跨网段、VPN、防火墙或无线隔离可能阻止发现，可按面板显示的地址手动连接；防火墙规则需由用户配置。

## 本机回环测试

在“连接与设置 → 连接诊断”点击“开始回环测试”。原生服务在 `127.0.0.1` 的随机端口创建节点和回环助手，通过真实 TCP 握手、收发与 ACK 检查本机链路。握手后自动选中助手，可发送文字、表情、图片和文件并接收回送。回环模式仅在本机运行；结束后点击“开启通信”恢复局域网模式。

切换连接模式会停止当前连接并保留联系人与历史。点击“停止通信”或“结束回环测试”回收助手临时数据。跨设备路由、防火墙与正式安装包按[原生服务验收](../../docs/testing.md#固定原生服务验收)另行检查。

## 表情、图片与文件

- 点击“表情与表情包”将 Unicode 表情插入草稿，或发送独立的大表情消息。大表情无需下载远程素材。
- 点击“发送图片”或“发送文件”，通过原生对话框选择文件；服务传输内容、名称与大小，系统路径留在本机。图片支持经解码校验的 PNG、JPEG、WebP，其他格式可作为普通文件传输。
- 单击图片展开预览，使用工具栏、滚轮、双指捏合或键盘缩放，拖动平移并复位。图片与文件的右键菜单也可通过 `Shift + F10` / 菜单键打开：图片提供“查看图片”和“另存为”，文件提供“另存为”。另存位置由系统对话框选择，接收后由用户主动预览或另存。
- 文字和表情正文最多 8192 UTF-8 字节，允许换行与制表符。图片最多 8 MiB，普通文件最多 1 GiB，均须非空。普通文件采用流式传输和校验。主节点与回环助手各有最多 2 GiB 的附件缓存；助手完成回送或停止测试后回收暂存。缓存满时清理历史后重试；历史淘汰或删除后回收未引用附件，在途使用的附件留待后续清理。完整额度、阶段超时与协议见[宿主 LAN 边界](https://github.com/YanChao001/serial-workbench/blob/main/docs/extensions.md#%E5%B1%80%E5%9F%9F%E7%BD%91%E9%80%9A%E4%BF%A1)。

选择文件后，消息气泡显示准备、校验、发送或接收阶段，以及本阶段字节数和百分比。阶段切换时重新计数，附件完整接收后才能预览或另存；“已送达”以对方原子保存后的回执为准。

传输期间可点击“停止传输”，原生服务会停止本次服务与连接，保留已有历史和草稿；它同时影响共享服务的其他窗口。已完成的发送不回滚，未收到送达回执时先核对对方记录，再决定是否重新连接并发送。

## 调整聊天布局

拖动会话列表右侧分隔条可调整会话栏宽度，拖动输入区上方分隔条可调整输入区高度。使用 `Tab` 聚焦分隔条后，左右方向键调整宽度，上下方向键调整高度；按住 `Shift` 使用较大步长，`Home` / `End` 调到当前窗口允许的最小 / 最大尺寸，双击恢复默认。拖动时按 `Escape` 取消本次调整。

布局尺寸通过会话检查点保留，界面重建后恢复，并随窗口空间约束到可用范围；窄窗口收起会话栏分隔条，保留聊天空间。“连接与设置”面板随内容收紧，受可视窗口高度限制，内容较多时在面板内滚动。

草稿检查点写入失败时保留待写内容并有限重试；持续失败时保留页面，待宿主保存结束、重新激活页面或打开“连接与设置”后重试。IP / 端口编辑随表单草稿恢复，启动和连接时校验。移除联系人前会确认同时移除其未发送草稿。

## 信任边界与数据

`messaging:lan` 是必需权限，涵盖监听、发现、连接、消息与附件传输，以及本服务的联系人、历史与附件缓存。文件操作仅处理用户主动选择的发送和另存；该权限独立于通用 HTTP、任意文件读取和系统凭据。打开已授权界面后自动监听与发现，连接和发送由用户操作；明确停止后，本次界面保持停止。

监听由原生服务持有，切页后继续收信。界面可见时每两秒读取状态，传输时每半秒读取进度，隐藏或卸载时清理轮询。点击停止、最后一个服务窗口关闭、撤销授权、替换或卸载插件、退出应用时，服务停止监听并回收连接与工作线程；多个窗口共享同一插件的服务。

读取失败时保留最后有效历史，显示错误并自动重试。后台刷新保留当前输入、联系人和已加载图片。

联系人最多 64 项、连接最多 16 个，保留最近 500 条消息，历史编码存档最多 1 MiB。联系人、历史与附件按插件 ID 隔离保存在宿主应用数据目录，独立于插件 KV 与笔记备份。历史以原子方式保存，schema 1 文本记录在下次修改时升级到 schema 2；损坏、未来版本、超限、链接或非普通文件保留原件并拒写，隔离恢复期间服务停用。

会话标题的更多菜单提供“清空历史消息”：确认后删除当前会话的本机消息，并回收未引用附件；联系人、草稿、其他会话、对方记录、原始文件和另存文件保留。“连接与设置 → 数据管理”可清空本机全部会话历史。确认区按 `Escape` 取消，结束后恢复入口焦点。

同一菜单提供会话导出，由 Wasm 校验后生成纯文本，通过宿主对话框保存。附件保留名称与大小标签，单次导出含标题、时间及说明最多 200 KiB，超出时标明省略的最早消息数。导出保留未发送草稿。

未发送草稿通过宿主检查点串行合并保存，发送期间的新编辑继续保留。未知版本或损坏的检查点保留原件并暂停修改和自动启动，仍可读取与导出已有聊天记录；先通过宿主会话工具导出原会话，再用匹配版本处理。

## 开发与验证

以下命令从市场仓库根目录运行：

```sh
cargo test --locked --manifest-path plugins/lan-chat/Cargo.toml --target-dir target/lan-chat-native
cargo clippy --locked --manifest-path plugins/lan-chat/Cargo.toml --target-dir target/lan-chat-native --all-targets -- -D warnings
node --test plugins/lan-chat/ui/main.test.mjs
cargo build --locked --release --target wasm32-unknown-unknown --manifest-path plugins/lan-chat/Cargo.toml --target-dir target/lan-chat
```

按[单插件验收](../../docs/testing.md#聚焦单个插件)运行手写 [`smoke.json`](./smoke.json)，检查真实 Wasm 的双语入口、文本与附件标签导出、非法状态拒绝。界面回归覆盖菜单、回执、授权 / 发送竞争及检查点；宿主 `extension_lan` 测试覆盖真实 TCP、附件、历史与生命周期。两台设备、系统对话框、窗口和防火墙按[原生服务验收](../../docs/testing.md#固定原生服务验收)检查。

原生服务统一通过 `starter.services.request("lan", request)` 调用，请求、响应与额度见[宿主 LAN 契约](https://github.com/YanChao001/serial-workbench/blob/main/docs/extensions.md#%E5%B1%80%E5%9F%9F%E7%BD%91%E9%80%9A%E4%BF%A1)。工具准备见[开发指南](../../docs/development.md)。
