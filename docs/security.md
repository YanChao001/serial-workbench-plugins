# 仓库安全规范

当前仓库的实现范围见 [README](../README.md#当前状态)。Node 插件运行、信任、安装和分发机制随宿主与市场的后续实现评审、验证并记录。

## 源码、依赖与凭据

提交前审核新增源码、依赖和资源的来源、用途、许可证及构建影响。依赖与工具可能在开发或构建机器上执行代码；审阅其安装和构建步骤，仅提供所需凭据。引入外部 GitHub Actions 时固定完整提交 SHA，并核对上游来源。

私钥、令牌、用户数据和敏感日志存放于受控渠道，保持在仓库及历史之外。日志和问题报告使用合成数据，移除凭据、授权头和私人内容。未经审阅的贡献在无生产凭据的环境中检查。

## 漏洞与凭据事件

通过宿主 [SECURITY.md](https://github.com/YanChao001/serial-workbench/blob/main/SECURITY.md) 提供的私密渠道报告；入口不可用时，先联系维护者请求私密渠道，再发送脱敏详情。

报告提供受影响仓库与提交、平台、合成数据复现、预期和实际结果及影响范围。发现凭据泄露时，私下通知维护者并保留必要证据，由维护者核对访问范围、撤销或轮换相关凭据。
