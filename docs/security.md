# 市场与插件安全规范

市场维护者审核并分发包，宿主执行安装与授权检查，用户决定启用和授予能力。发布操作见 [发布与维护](./publishing.md)，故障处理见 [排障手册](./troubleshooting.md)。

## 信任与职责

| 边界                 | 负责方     | 必须保证的内容                                                                   |
| -------------------- | ---------- | -------------------------------------------------------------------------------- |
| 插件逻辑、状态与输入 | 插件作者   | 校验动作、字段、导入状态和效果回执；为业务不变量和异常路径编写测试               |
| 收录与分发           | 市场维护者 | 审核源码、来源、许可证、依赖、权限和生成产物；保护签名私钥；按期续签和处理下架   |
| 安装与能力执行       | 宿主       | 验签、版本及哈希检查、安装身份、授权、网络和存储边界、调度、超时、取消及视图解析 |
| 启用与主动发送       | 用户       | 审阅来源和权限，决定是否启用、授予可选能力、发送所选数据或保存产物               |

目录签名认证受信发布密钥和 payload 完整性；清单 `author` 为作者自述，身份与源码仍需审核。市场来源收据绑定仓库、公钥指纹、目录修订和完整包哈希，由宿主验证后建立。

未来条目隔离保留完整目录的验签、元数据与防回退检查，下载和安装要求条目兼容，见 [架构说明](./architecture.md#兼容与演进)。

市场 JavaScript 检查负责签名前审核；宿主 Rust 负责清单、ABI、视图、权限及运行时检查。

## 插件审核

提交收录前审阅源码和锁文件，确认身份、版本、许可、入口及权限与功能相符。依赖须有明确用途、可信来源和可接受许可；网络、存储、文件输入与凭据使用须说明数据范围和失败行为。

- 优先将增强功能声明为可选权限，让未授权用户仍能使用离线部分。每条命令声明启动门槛；授权主体是整个插件，不能把命令门槛误认为该命令运行后的权限上限。
- 插件校验集合长度、数字和日期范围、枚举、索引、状态版本、历史与导入数据。
- 所有 `host-result` 都核对效果 ID、值和结构化错误。存储使用宿主快照的 revision，冲突时保留草稿并提示重新读取，不静默覆盖其他窗口。
- 效果按项执行；取消、超时或后续视图错误可能发生在写入和网络操作之后。按匹配回执判断完成状态，响应省略时由用户核对后决定是否重试。
- 导出采用受限产物，文件名和内容按实际格式校验，不接受宿主路径。Markdown、表格、HTML 特殊字符和 CSV 公式前缀按各输出用途处理，不把用户文本拼接为可执行内容。
- 权限拒绝、旧状态或损坏状态、存储冲突和取消应返回明确结果，保存成功以真实完成回执为准。

精确协议、额度和运行边界见配套宿主的[扩展指南](https://github.com/YanChao001/serial-workbench/blob/main/docs/extensions.md)及源码。

## 执行隔离与数据能力

插件业务交付 Extism Wasm，界面采用通用视图或包内单文件 HTML / CSS / JavaScript。语言与执行上下文见 [架构说明](./architecture.md#语言与-wasm)。

自定义 UI 使用无同源权限的 sandbox、独立 CSP 与受限消息桥，通过 SDK 操作当前会话、本命令动作、产物及获授权的固定服务；通用网络、KV 和凭据经 effects。HTML 保持自包含，外部内容用安全文本节点呈现。平台注入、消息身份和 CSP 见 [宿主自定义界面](https://github.com/YanChao001/serial-workbench/blob/main/docs/extensions.md#%E8%87%AA%E5%AE%9A%E4%B9%89%E7%95%8C%E9%9D%A2)。

HTML 属于可执行源码，检查点须报告真实未保存状态，输入与关闭流程按 [测试规范](./testing.md#界面与安装验收) 验证。UI 脚本运行于 WebView，Wasm 计算与内存预算只约束业务模块。

Wasm 限制导入、线性内存、执行预算和输出，worker 子进程提供终止与故障恢复。worker 以当前用户身份运行，**不提供额外的操作系统权限沙箱**；审计范围包括 Wasmtime / Extism、宿主 broker、进程协议和平台配置。

文件内容来自用户显式选择，路径留在宿主。普通 HTTP effect 的来源和方法须在清单声明并获授权；公网 HTTPS、本机来源及下文图片资源分别检查权限。系统凭据由宿主按扩展、来源和别名注入，秘密原文留在宿主。插件功能说明须交代发送内容和接收服务，包括 URL 查询参数中的数据。

私有存储按插件 ID 隔离，卸载默认保留数据；同 ID 重装并重新授权后可访问原空间，因此每个产品须使用独立稳定 ID。凭据使用系统凭据服务，备份由插件说明其语义。会话导出可能含用户输入、草稿和状态，分享前由用户审阅。

## 原生服务与外部来源

固定服务及权限见 [调用入口](./development.md#固定原生服务)。宿主为每次请求补充插件身份、模块哈希、安装代次和原生窗口，核对启用、授权及生命周期。`window` 只控制调用插件独立原生窗口的置顶状态，完整规则见 [宿主自身窗口服务](https://github.com/YanChao001/serial-workbench/blob/main/docs/extensions.md#%E6%8F%92%E4%BB%B6%E8%87%AA%E8%BA%AB%E7%AA%97%E5%8F%A3)。撤权与安装变更由服务门闩协商，停止等待后仍须核对此前副作用。

**LAN** 支持同网段设备公告发现。打开已授权界面会启动监听和有界 UDP 公告，用户点选设备或手填允许的数字私有、回环或本地链路 IP 后建立 TCP 连接。公告地址取自 UDP 源地址，临时展示；联系人在真实握手后建立。公告、消息和附件为明文且无远端身份认证，**仅适用于可信局域网，勿发送秘密**。持久保存由对端 ACK 确认。本机回环在 `127.0.0.1` 使用真实 TCP，仅验收当前设备链路。允许地址、发现额度与生命周期见 [宿主 LAN 边界](https://github.com/YanChao001/serial-workbench/blob/main/docs/extensions.md#%E5%B1%80%E5%9F%9F%E7%BD%91%E9%80%9A%E4%BF%A1)。

`messaging:lan` 提供有界附件传输和缓存，发送与另存经系统对话框选择，附件不自动打开或执行。图片真实解码后提供受控预览，普通文件显示元数据卡片。会话文本导出只含附件标签；路径校验、单文件与缓存额度由宿主维护。

联系人和历史由原生服务按插件隔离，与 KV 分开；链接、损坏或未来存档保留原件并拒写。连接属于原生窗口，导航后继续接收；停止、关闭与撤权回收见 [内网通信说明](../plugins/lan-chat/README.md#信任边界与数据)。

**图源与来源** 由壁纸插件维护。Wasm 通过声明并授权的 HTTPS GET 来源读取公开列表，校验输入、响应、图片身份与匹配回执，失败保留原成功筛选。站点、适配和图片使用许可见 [壁纸说明](../plugins/wallpaper-browser/README.md#图源预览与资源)；图片许可由原站及权利人决定。

**图片资源** 使用独立可选权限 `network:images`，允许任意公共 HTTPS URL 的 GET；查询参数可携带数据，须审阅发送用途。宿主核验 HTTPS、证书、无重定向、响应字节、MIME 和真实解码，仅发送固定 User-Agent。资源返回短期不透明 `resourceId` 与元数据，预览使用安全 data URL，另存经系统对话框选择。

资源绑定插件、模块哈希、安装代次和原生窗口，受有效期、数量、字节与解码额度限制。关闭、撤权或安装变更清理关联资源；会话导入后须重新获取。精确规则见 [宿主图片资源边界](https://github.com/YanChao001/serial-workbench/blob/main/docs/extensions.md#%E5%A3%81%E7%BA%B8%E5%9B%BE%E5%BA%93%E4%B8%8E%E5%9B%BE%E7%89%87%E6%90%9C%E7%B4%A2)。

**网络传输** 使用宿主连接设置，基础网络、声明来源 / 方法和代理权限分别授权。`networkMode`、授权回落、本机来源及代理排除规则见 [宿主来源与授权](https://github.com/YanChao001/serial-workbench/blob/main/docs/extensions.md#%E6%9D%A5%E6%BA%90%E4%B8%8E%E6%8E%88%E6%9D%83)，操作见 [网络连接](../plugins/wallpaper-browser/README.md#网络连接)。

公共 HTTPS 直连核验全部解析地址并固定连接目标，拒绝 Fake-IP 等非公网地址；命中代理排除后执行同样检查。`network:local` 按本机来源规则工作。代理可位于本机或内网，远端解析时最终 IP 由代理控制，宿主仍检查 HTTPS、证书、无重定向和内容限制。

**图库与外链** 分别授权。`wallpapers:manage` 管理现有图库和应用背景；远程资源重绘压缩后导入并执行配额，背景写入使用 revision CAS，保留其他偏好。`links:open` 经系统浏览器打开公共 HTTPS 名称，URL 校验拒绝本机名称、IP 字面量和其他协议，最终 DNS 与连接由浏览器负责。拒绝可选网络能力后，本机图库仍可用。

## 密钥与构建隔离

生产私钥放在 GitHub Secret `MARKET_SIGNING_PRIVATE_KEY`，或由 `MARKET_KEY_FILE` 指定的仓库外受保护文件。`public-key.txt` 公开保存公钥；私钥、令牌、用户存档和敏感日志保持在仓库及其历史之外。

普通开发与 PR 检查不需要私钥：`check.mjs` 使用仅驻留内存的一次性 Ed25519 密钥执行离线验签。构建脚本向 Cargo 和宿主工具传递的环境会移除 `MARKET_SIGNING_PRIVATE_KEY` 与 `MARKET_KEY_FILE`。生产 Actions 将构建和签名放在独立 job 中，生产密钥仅注入不执行插件构建的签名步骤，签名前再次核对已审核清单与包哈希。

签名和发布有界读取文件，JSON 与 HTML 严格检查 UTF-8，路径拒绝符号链接 / junction。签名对照审核过的清单与 HTML，复核模块、UI、规范包字节、Base64、签名和字段结构。发布只上传新建临时目录的已验证字节快照，含三份项目许可文件，见 [生产发布](./publishing.md#actions-生产发布)。

Cargo 依赖和工具链代码会在构建机执行。审核依赖变更，仅提供构建所需凭据；未经审阅的 PR 使用无生产 Secret 的环境。日志保留版本、哈希、错误码与必要上下文，移除 Authorization、秘密、用户内容和完整会话。

外部 Actions 固定到完整 SHA，升级时核对上游仓库与提交。宿主固定与工具链选择见 [发布指南](./publishing.md#固定配套宿主)。

续签、回退、密钥轮换与失败恢复见 [发布与维护](./publishing.md)，恢复过程保持验签和修订递增。

## 漏洞与密钥事件

通过宿主 [SECURITY.md](https://github.com/YanChao001/serial-workbench/blob/main/SECURITY.md) 提供的私密渠道报告。入口不可用时，先通过维护者公开联系方式请求私密渠道，再提交脱敏详情。

报告提供宿主与市场提交、插件 ID / 版本、平台、合成数据复现、错误码与影响范围。恶意包、密钥泄露或签名链问题保留包哈希、目录 payload 和发布时间，及时私下联系维护者。

维护者评估范围，必要时撤销发布凭据、轮换密钥并发布更高修订的修复目录。下架阻止新下载，已安装或复制的包仍由用户持有；需要禁用、卸载或升级时明确通知用户。
