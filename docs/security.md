# 安全规范

新增源码、依赖、资源和 Actions 审核来源、用途、许可、执行步骤及平台影响，外部 Action 固定完整 SHA。未经审阅的贡献在无生产凭据环境检查。

私钥、令牌、用户数据和敏感日志保持在仓库及历史之外；仅提供必需凭据，报告使用合成数据并移除授权头和私有内容。

漏洞通过宿主 [SECURITY.md](https://github.com/YanChao001/serial-workbench/blob/main/SECURITY.md) 的私密渠道报告，提供仓库/提交、平台、合成复现和影响。凭据泄露私下通知并撤销或轮换，保留必要事件证据。

Node 执行、安装、信任和分发机制随实际实现单独评审与验收，当前范围见 [README](../README.md)。
