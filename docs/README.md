## 维护规则

工程文档使用中文、UTF-8 和可读链接。同一事实在一处定义，其余使用链接；当前功能、已验证行为与后续计划分别说明。工具、契约和流程实际建立后再编写相应操作指南，并加入本索引。

修改文档时核对文件路径、标题锚点、命令的工作目录与 shell，以及命令所依赖的实际入口。项目身份与 Node 开发约束以 [package.json](../package.json) 为准。检查结果与未测范围写入 PR。

提醒应说明影响决策的具体条件、后果和下一步，放在相关操作旁；删去不影响操作或判断的说明，保留真实的数据、安全和法律边界。
